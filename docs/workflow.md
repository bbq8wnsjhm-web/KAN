# Рабочий процесс

Корень проекта — это чистая папка live-сайта. В ней должны оставаться только файлы, которые нужны для открытия и поддержки сайта.

## Базовый принцип

- `media/` — только подключенные к сайту изображения, видео, шрифты и QR.
- `docs/` — короткие правила и карта ассетов.
- `tools/` — локальные служебные скрипты.
- Исходники, архивы, черновые рендеры и временные файлы храним вне папки live-сайта.

## Форматы видео

- Для сайта основной формат — `mp4`.
- `mov` используем только как исходный, монтажный или архивный формат вне live-папки.
- В HTML не подключаем `mov` напрямую.
- Все фоновые ролики должны быть без аудио, чтобы autoplay работал стабильно.
- Для фонового видео используем атрибуты `autoplay`, `muted`, `loop`, `playsinline`, а при необходимости `poster`.

## Перед добавлением нового видео

- Подготовлена ли web-версия в `mp4`.
- Достаточно ли малый вес файла для фоновой загрузки.
- Нет ли аудиодорожки.
- Зациклено ли видео без заметного шва.
- Нужен ли `poster`, чтобы не было пустого кадра при загрузке.
- Добавлен ли ролик в `docs/asset-map.md`.

## Имена файлов

Для live-сайта используем стабильные имена:

- `main-bg.mp4`
- `kto-bg.mp4`
- `find-bg.mp4`
- `what-bg.mp4`

Версионные, черновые и мастер-файлы не складываем в корень проекта и `media/`.
