# Сайт клуба

Готовый статический сайт клуба графического дизайна лежит в этой папке проекта.

- `index.html` — главная страница.
- `kto-my.html`, `chto-my-delaem.html`, `kak-naiti.html` — внутренние страницы.
- `styles.css` и `script.js` — общий внешний вид и поведение.
- `media/` — файлы, которые реально нужны сайту.
- `docs/` и `tools/` — заметки по проекту и локальные рабочие скрипты.

Фоновая музыка убрана полностью: на сайте больше нет аудиотега, автозапуска музыки и сохранения позиции аудио в браузере.

## Быстрый старт

Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\start-preview.ps1
```

После запуска сайт будет доступен по адресу `http://localhost:8000`.

## Видео

Для фоновых сцен используется web-формат `mp4`. Формат `mov` считается исходником и не подключается напрямую к HTML.

Если нужно пересобрать web-версию из нового `.mov`, положите исходник вне рабочей папки сайта и укажите путь к нему:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\convert-mov-to-mp4.ps1 -InputPath "C:\path\to\source.mov" -OutputPath ".\media\main-bg.mp4" -Crf 24 -Preset slow
```

Скрипт использует FFmpeg, делает `mp4` на `libx264`, добавляет `+faststart` и по умолчанию убирает аудио.

## Правило папки проекта

- В `media/` держим только подключенные к сайту изображения, видео, шрифты и QR.
- Тяжелые исходники, архивы, временные профили браузера и проверочные скриншоты не должны попадать в рабочую папку сайта.
- Если добавляется новый медиафайл, сначала проверяем его вес и фиксируем назначение в `docs/asset-map.md`.
